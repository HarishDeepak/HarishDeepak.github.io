A robot that learns from its own mistakes, without retraining

PragmaBot (Qu et al., IEEE RA-L 2026) keeps a vision-language model frozen and changes only its context: the robot writes critiques of its own failures into memory and reads them back next time. The published code stops at planning and leaves execution as NotImplementedError. This project put it on a real Franka FR3.

The execution layer

A ROS 2 bridge exposes three skills to the planner (pick, place and push), one action call each. They are driven by MoveIt 2 free-space planning plus Cartesian approach, lift and push strokes, with joint-velocity checks and a table collision scene. Every skill returns a success flag and a failure message, and that message is exactly what the planner reflects on.

The bug that was really a depth problem

Grasps kept landing in the air beside objects. The cause was stereo "flying pixels" at object edges, which stretched the reconstructed object far behind itself. Mask erosion, a median-absolute-deviation depth filter and a scale-aware crop fixed it:

After ArUco hand-eye calibration (easy_handeye2), the arm reached commanded poses with about 1 mm error.

One run picked up a sponge to push an object too small to grip, a tool use that came from a stored lesson rather than a rule. The full-memory setting also needed 1.9× the prompt tokens of retrieval.

Read these numbers carefully

Five human-judged runs per condition. That shows the effect exists on this robot; it is not a statistical result.

GraspGen's confidence is the model's own score, not a measured grasp success rate.

The planner, memory and retrieval are upstream PragmaBot, kept as-is apart from the FR3 prompts. The paper's image-annotation module was not reimplemented, and push moves a fixed 12 cm.
